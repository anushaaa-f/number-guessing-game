# Number Guessing Game 🎯

A simple Python game where the computer generates a random number between 1 and 100, and the user gets 6 chances to guess it.

### Features

* Random number generation
* 6 guessing attempts
* Higher/lower hints
* Game stops when the correct number is guessed

### Concepts Used

* Random module
* For loop
* If-elif-else
* Break statement
* For-else

### Run

```bash
python number_guessing_game.py
```
